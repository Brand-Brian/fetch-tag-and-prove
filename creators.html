Creator questions

How big does my audience need to be?

There's no minimum. FETCH pays on conversion, not reach. The pilot cohort is picked on fit with the destination and how much an audience trusts a recommendation — not follower count.

When do I actually get paid?

After the guest's stay completes and the property confirms it. Cash, not credits. During the pilot payouts run monthly against a reconciliation statement; instant splits come with the full platform.

What if someone books a week later, on a laptop?

That's what the code is for. Links break across devices; codes don't. If your code is on the reservation, the credit is yours regardless of when or where it was made. See how attribution works.

Does the traveller pay more?

Never. Same room, same rate, same booking page they'd get going direct. The only difference is that you get credited for the demand.

What happens if a booking is cancelled?

Nothing is owed and nothing is paid. Commission only exists on a completed stay — that's what keeps properties comfortable paying it.

Can I see what's converting?

Yes. The creator dashboard shows taps, bookings, verified stays and money owed per link — the same records the property sees. Open the demo dashboard.

BC coast, hand-matched pairings, every booking verified by hand so the proof is airtight. If that's your patch, come in early.
